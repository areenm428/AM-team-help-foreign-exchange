## 🚀 Getting Started Now

### Step 1: Start Backend
```bash
cd app-backend
npm install
npm start
```
✅ Backend runs on: `http://localhost:5000`

### Step 2: Start Frontend
```bash
cd app-frontend
python -m http.server 8000
```
✅ Frontend runs on: `http://localhost:8000`

### Step 3: Open App
Visit: **http://localhost:8000** 🎯

### Step 4: Add Contacts
1. Click "Add Contact"
2. Fill team member details
3. Include WhatsApp number (with country code)
4. Save! ✅

### Step 5: Send Messages
1. Find contact in "All Contacts"
2. Click "Chat" button
3. WhatsApp opens automatically
4. Send message! 💬

## 📱 WhatsApp Integration

### How It Works
1. **Store WhatsApp Numbers** - In application
2. **Click Chat Button** - Opens WhatsApp automatically
3. **Message Opens** - Pre-filled with contact
4. **Start Conversation** - Send messages directly

### Format Required
- Country code: `+91` (India), `+1` (USA), etc.
- Number: `+91-9876543210`
- With dashes or spaces is fine

### WhatsApp Groups
- Generate links for each team
- Share with group members
- Easy collaboration
